# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-10-03

### Added

- Adult BMI calculation with WHO classification bands
- Youth-oriented copy for ages under 18 (no adult WHO bands)
- Healthy weight range for the entered height (BMI 18.5–24.9)
- Multiple local profiles with optional goal weight
- Per-profile history (up to 20 readings) with trend chart and detail
- Share sheet for BMI results
- Kilogram/pound and centimeter/meter unit toggles
- Light and dark themes that follow the system
- Responsive layout for narrow and wide screens
- Persian RTL interface with Vazirmatn
- Feature-first Clean Architecture with MVVM presentation
- Community docs: contributing guide, code of conduct, security policy, accessibility notes
- Issue forms, pull request template, and CI (analyze + test)
